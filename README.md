# JavaScript QA Automation Projects

Учебные проекты по автоматизации тестирования на JavaScript, выполненные в рамках обучения QA.

Репозиторий является fork учебного репозитория Нетологии. Мои выполненные и доработанные задания находятся в разделах `7.3`, `7.4/puppeteer` и `7.5`.

## Реализованные проекты

### Jest

В разделе `7.3` реализованы unit-тесты с использованием Jest.

Проверяется работа функции сортировки данных, включая различные входные условия.

Используется:

- JavaScript
- Jest
- Code Coverage

### Playwright

Реализованы UI-тесты с использованием Playwright.

Проверяются пользовательские сценарии веб-приложения, включая авторизацию.

Используется:

- JavaScript
- Playwright
- UI Testing

### Puppeteer

В разделе `7.4/puppeteer` реализованы браузерные UI-тесты.

Проверяются:

- отображение элементов страницы;
- ссылки;
- заголовки страниц;
- пользовательские переходы.

Используется:

- JavaScript
- Puppeteer
- Jest

### Puppeteer + Cucumber

В разделе `7.5` реализованы автоматизированные сценарии тестирования сервиса бронирования билетов.

Используются:

- Puppeteer;
- Cucumber;
- BDD-сценарии;
- пользовательские UI-сценарии.

## Технологии

- JavaScript

## Назначение проекта

Репозиторий демонстрирует практику работы с различными инструментами автоматизации тестирования на JavaScript и знакомство с подходами UI-, unit- и BDD-тестирования.
